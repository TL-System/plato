├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  OLD CODE (still works):                                                 │
│  ════════════════════════                                                │
│  class MyServer(fedavg.Server):                                          │
│      def aggregate_deltas(self, updates, deltas):                        │
│          # Custom aggregation logic                                      │
│          return custom_agg(deltas)                                       │
│                                                                           │
│      def choose_clients(self, pool, count):                              │
│          # Custom selection logic                                        │
│          return custom_select(pool, count)                               │
│                                                                           │
│  server = MyServer(...)                                                  │
│                                                                           │
│  ✅ Detection mechanism:                                                 │
│     - Checks if method is overridden using type() inspection            │
│     - If overridden: uses subclass method (legacy path)                  │
│     - If not overridden: delegates to strategy (new path)                │
│                                                                           │
│  NEW CODE (recommended):                                                 │
│  ════════════════════════                                                │
│  class CustomAggregation(AggregationStrategy):                           │
│      async def aggregate_deltas(self, updates, deltas, context):         │
│          # Custom aggregation logic                                      │
│          return custom_agg(deltas)                                       │
│                                                                           │
│  class CustomSelection(ClientSelectionStrategy):                         │
│      def select_clients(self, pool, count, context):                     │
│          # Custom selection logic                                        │
│          return custom_select(pool, count)                               │
│                                                                           │
│  server = fedavg.Server(                                                 │
│      aggregation_strategy=CustomAggregation(),                           │
│      client_selection_strategy=CustomSelection()                         │
│  )                                                                        │
│                                                                           │
│  ✅ Benefits of new approach:                                            │
│     - Composable: mix with other strategies                              │
│     - Testable: test without server infrastructure                       │
│     - Reusable: use across different server types                        │

┌───────────────────────────────────────────────────────────────────────────┐
│                      IMPLEMENTATION DETAILS                               │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  ServerContext (shared state):                                           │
│  ─────────────────────────────                                           │
│    • server: Reference to server instance                                │
│    • trainer: Reference to trainer                                       │
│    • algorithm: Reference to algorithm                                   │
│    • current_round: Current training round                               │
│    • total_clients: Total number of clients                              │
│    • clients_per_round: Clients selected per round                       │
│    • updates: List of client updates                                     │
│    • state: Dict for strategy-specific state (e.g., PRNG)                │
│                                                                           │
│  Strategy Lifecycle:                                                     │
│  ──────────────────                                                      │
│    1. Construction: strategy = Strategy(params...)                       │
│    2. Injection: server = Server(aggregation_strategy=strategy)          │
│    3. Setup: strategy.setup(context) [called in server.configure()]      │
│    4. Execution: strategy.method(args, context) [called per round]       │
│                                                                           │
│  Key Methods:                                                            │
│  ────────────                                                            │
│    AggregationStrategy:                                                  │
│      • setup(context)                                                    │
│      • aggregate_deltas(updates, deltas, context) → aggregated_deltas    │
│      • aggregate_weights(updates, baseline, weights, context) → weights  │
│                                                                           │
│    ClientSelectionStrategy:                                              │
│      • setup(context)                                                    │
│      • select_clients(pool, count, context) → selected_clients           │
│      • on_clients_selected(selected, context)                            │
│      • on_reports_received(updates, context)                             │
└───────────────────────────────────────────────────────────────────────────┘
