# LeRobot and SmolVLA integration retired

This integration was retired from the supported runtime in October 2026.
Its original source, configurations, tests, and runbook are preserved in the
[lerobot archive](https://github.com/TL-System/plato/tree/main/archives/retired/lerobot),
with provenance and isolated historical-restoration instructions.

The Qwen3 [federated LoRA example](6. Qwen3 Federated LoRA.md) covers text-model
adaptation. It does not replace robotics policy training; Plato has no
maintained replacement for this retired robotics integration.

Historical runbooks are unverified on the current dependency stack.
