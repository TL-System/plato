# Nanochat integration retired

This integration was retired from the supported runtime in October 2026.
Its original source, configurations, tests, and runbook are preserved in the
[nanochat archive](https://github.com/TL-System/plato/tree/main/archives/retired/nanochat),
with provenance and isolated historical-restoration instructions.

For the maintained text-model reference, use
[Qwen3 Federated LoRA](6. Qwen3 Federated LoRA.md), which uses the existing
Hugging Face trainer and PEFT adapters. Nanochat configurations, tokenizer
build steps, and CORE evaluation belong to the historical environment.

Historical runbooks are unverified on the current dependency stack.
